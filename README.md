# Desarollo-de-Apps

## Aplicación de transporte Ionic

El frontend de la plataforma de viajes está en [`uber-ionic/`](uber-ionic/) y consume la API documentada en [`API_DOCUMENTATION.md`](API_DOCUMENTATION.md).

Para ejecutarlo localmente:

```powershell
cd uber-ionic
npm install
npm start
```

La URL base de la API se configura en `uber-ionic/src/environments/environment.ts`.
